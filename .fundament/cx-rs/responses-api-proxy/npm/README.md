# @openai/cx-responses-api-proxy

<p align="center"><code>npm i -g @openai/cx-responses-api-proxy</code> to install <code>cx-responses-api-proxy</code></p>

This package distributes the prebuilt [CX Responses API proxy binary](https://github.com/openai/cx/tree/main/cx-rs/responses-api-proxy) for macOS, Linux, and Windows.

To see available options, run:

```
node ./bin/cx-responses-api-proxy.js --help
```

Refer to [`cx-rs/responses-api-proxy/README.md`](https://github.com/openai/cx/blob/main/cx-rs/responses-api-proxy/README.md) for detailed documentation.
